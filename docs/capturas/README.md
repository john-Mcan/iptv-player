# Capturas

Imágenes que usa el README principal.

| Archivo | Qué muestra |
|---|---|
| `tv-en-vivo.png` | Pestaña TV en vivo con un canal reproduciéndose y la guía (EPG) a la vista. Es la captura principal. |
| `peliculas.png` | Grilla de pósters con «Continuar viendo» y su barra de progreso. |
| `series.png` | Una serie abierta en temporadas o episodios. |
| `pip.png` | La ventana PiP flotando sobre el escritorio. |
| `configuracion.png` | Opcional: ventana de configuración. |
| `demo.gif` | Opcional: 10 a 15 segundos (cargar lista → reproducir → PiP), menos de 5 MB. |

## Cómo sacarlas

- PNG, con la ventana en unos 1600 × 900.
- Usa una lista pública y legal, por ejemplo los canales abiertos de [iptv-org](https://github.com/iptv-org/iptv).
- Que no se vea la URL de ningún proveedor privado: las URLs de Xtream llevan usuario y contraseña.
- Sin escritorio ni datos personales alrededor (salvo en `pip.png`, que muestra el PiP sobre un escritorio limpio).
